## Space Deep Dive: `gokaygokay/AuraSR-v2`

**Creator:** gokaygokay (based on fal.ai's model)
**Space:** https://huggingface.co/spaces/gokaygokay/AuraSR-v2
**Model:** https://huggingface.co/fal/AuraSR-v2
**Likes:** 622 · **Runtime:** ZeroGPU (GPU-accelerated)

**What it does:** AuraSR-v2 is a GAN-based super-resolution upscaler that takes any image and blows it up **4×** in a single forward pass — no expensive diffusion steps, no waiting. It's a reproduction of Adobe's GigaGAN architecture, trained by fal.ai to handle real-world degradation (JPEG artifacts, low-res textures) that v1 struggled with. The Space uses Gradio's `ImageSlider` component to let you drag a comparison bar between the input and the upscaled output — you see the exact improvement in real time. It hits **~0.25 seconds** for a 4× upscale on GPU, which is orders of magnitude faster than diffusion-based upscalers.

**Tech stack:** Gradio + `@spaces.GPU` decorator (ZeroGPU) + fal's `aura-sr` Python package (PyTorch, 600M params, GAN generator). The secret sauce is `upscale_4x_overlapped` — it tiles the image with overlap and averages passes to eliminate seam artifacts. During training, fal fixed the tile mismatch (v1 trained on whole images but inferred on tiles) and added JPG degradation preprocessing, which made v2 work well on real photos not just AI-generated art.

**Why it's interesting:** This is a rare example of a GAN-based approach competing head-to-head with diffusion for image enhancement — and winning on speed by a huge margin. It's also a great case study in iterative open-source model improvement: fal released v1, got community feedback about seams and JPG artifacts, and fixed both in v2 with training data changes (tile-stratified training + degradation augmentation) rather than just patching inference. The Space itself demonstrates a clean Gradio pattern with the `ImageSlider` comparison widget that's worth stealing for any before/after demo. ZeroGPU keeps it free to run without eating inference credits.

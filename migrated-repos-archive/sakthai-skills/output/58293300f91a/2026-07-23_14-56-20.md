## 🌀 IllusionDiffusion by AP123

**Space:** [`AP123/IllusionDiffusion`](https://huggingface.co/spaces/AP123/IllusionDiffusion) (5.4k likes, ZeroGPU-a10g)

**What it does:** Generates high-quality illusion artwork — you supply a pattern image (a logo, word, QR code, or any shape) plus a text prompt, and Stable Diffusion produces a photorealistic scene that *visually encodes* that pattern into the image. The pattern is invisible at a glance but emerges when you look closely or scan it. Think "QR code monster" meets artistic photorealism.

**How it works — the architecture is clever:** It chains *two* ControlNet pipelines. First, the `main_pipe` (StableDiffusionControlNetPipeline) runs 15 steps at 512×512 using a specialized ControlNet model called `monster-labs/control_v1p_sd15_qrcode_monster` — this ControlNet was trained specifically to embed QR-style patterns into generated imagery. The latent output is then upscaled 2× (nearest-exact), and fed into `image_pipe` — a ControlNet *img2img* pipeline that runs 20 more steps at 1024×1024 using the same high-res pattern as control, adding detail and realism. Base model is `Realistic_Vision_V5.1_noVAE` for photorealism, with DPM++ Karras SDE or Euler schedulers. Conditioned on ZeroGPU (zero-a10g), so inference is free.

**Why it's interesting:** Unlike typical ControlNet "style transfer," this is a functional illusion — the pattern isn't just a style reference, it's *structurally embedded* so it survives scanning. It's the same technique behind those viral "QR code that blends into art" generators, but open-source, running on free GPU, and tuned for aesthetic quality. The two-stage (latent diffusion → upscale → img2img refinement) approach is a solid blueprint for anyone building production ControlNet apps — keeps first pass fast, second pass detailed. Building a similar Space would just need: a ControlNet model, Realistic Vision base, two pipeline instances, and Gradio.

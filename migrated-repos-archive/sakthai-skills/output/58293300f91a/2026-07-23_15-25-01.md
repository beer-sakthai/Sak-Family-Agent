**Space: AI4Editing/MagicQuill** — *MagicQuill: An Intelligent Interactive Image Editing System* (CVPR 2025)

MagicQuill is a Gradio 5-powered interactive image editing system accepted at CVPR 2025. Unlike conventional inpainting or text-prompt-based editors that require laborious mask painting and prompt engineering, MagicQuill uses a **multimodal large language model (MLLM)** to watch your brush strokes in real time and predict what you intend to do — no explicit text prompts needed. Scribble on the image to add objects, erase by stroking with removal intent, or paint over regions to change color, and the system infers the operation automatically. The core architecture wraps a Stable Diffusion 1.5 backbone (realisticVision V6) with a **two-branch plug-in module** — BrushNet for structure-aware inpainting, a ControlNet scribble/edge branch for shape guidance, and a color ControlNet for palette-driven recoloring. It also runs a PiDiNet scribble preprocessor and a line-art processor to extract edge conditions from user strokes.

Technically, the repo is a substantial Gradio Blocks application (~350 lines of `app.py`) backed by a full ComfyUI-style inference pipeline (`MagicQuill/` directory) with custom Comfy nodes for BrushNet loading, blended inpainting, multi-controlnet application, and a custom `ScribbleColorEditModel` class that orchestrates the entire diffusion chain. The Space uses ZeroGPU (`@spaces.GPU(duration=20)`) with a 20-second dynamic GPU allocation — enough for 20-step Euler ancestral sampling at 512px. It downloads ~6 GB of checkpoints (SD 1.5 models, ControlNet variants, BrushNet weights) from `LiuZichen/MagicQuill-models` on cold start. The UI features a custom `MagicQuill` Gradio component (packaged as a `.whl`) that captures canvas strokes and communicates intent via a structured JSON payload to the backend.

What makes this Space remarkable is how it collapses the traditionally multi-step image editing workflow (select region → pick tool → tune prompt → inpaint) into a single "sketch-to-edit" interaction. The MLLM guess_prompt endpoint (commented out in this demo but live on the official site at https://magicquill.art) further eliminates the need for manual prompt entry entirely. With 2,295 likes and acceptance to CVPR 2025, it's a strong example of how diffusion priors + intent-aware interfaces are pushing image editing toward something that feels closer to drawing with a smart brush than wrestling with a toolchain.

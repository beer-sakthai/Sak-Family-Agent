## 🧠 Space Deep Dive: `deepseek-ai/Janus-Pro-7B` — Unified Understanding & Generation

**Janus-Pro-7B** is DeepSeek's unified multimodal model that does what most models can't — it both **understands** images (answering questions about them) and **generates** them from scratch, all in a single autoregressive framework with one transformer backbone. Unlike earlier unified models that force the same visual encoder to serve both roles (creating a conflict), Janus decouples the vision pathways: **SigLIP-L** (384×384 input) handles multimodal understanding, while a **LlamaGen VQ tokenizer** (downsample rate 16) handles image generation, both feeding into a shared DeepSeek-LLM-7B-base transformer. This architectural separation is the core innovation — it lets each pathway specialize, and the paper (arXiv 2501.17811) shows it matches or beats task-specific models on both benchmarks.

The Space itself is a **Gradio 5.13.2** app with two clean tabs. The **Multimodal Understanding** tab takes an image + question and returns text answers (great for meme explanations, equation-to-LaTeX, visual QA). The **Text-to-Image** tab generates 4 parallel images from a prompt at 384×384, then passes them through **Real-ESRGAN** for 2× upsampling to 768×768. Under the hood it uses classifier-free guidance (CFG), autoregressive token generation through a custom `gen_head`, and a VQ codebook decoder — all accelerated via **ZeroGPU** (`@spaces.GPU(duration=120)`) so inference runs free on HF's GPU pool. With **2,016 likes** and active since January 2025, it's one of the most compelling examples of the "one model does both" paradigm on the Hub. 🚀

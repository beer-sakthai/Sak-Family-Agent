### Wan2.2 Animate — *by Wan-AI*

**What it does.** Wan2.2 Animate is an image-to-video character animation Space that lets you upload a reference image of a character and a short video, then either (a) animate the character using the video's motion (Move mode), or (b) replace the character in the video with your own image (Mix mode). Think of it as a motion-transfer pipeline: give it a static photo and a clip of someone dancing, and it outputs a video of *your* character dancing with the same motion. The Space runs on **Gradio 5.47.2** on `cpu-basic` hardware and uses **Dashscope API** (Alibaba Cloud's AI gateway) to call the Wan2.2-Animate-14B model behind the scenes, handling file uploads through Alibaba OSS for temporary storage.

**What makes it interesting.** It's one of the first open-access Spaces to put character-aware motion transfer behind a simple Gradio UI — no Colab notebooks, no local GPU needed. It supports two quality presets (`wan-pro` at 25fps/720p and `wan-std` at 15fps/720p), accepts video up to 30 seconds and 200 MB, and auto-caches examples so you can try it instantly. The underlying model is Apache 2.0 licensed, and the code is fully visible. The app's `app.py` (353 lines) is a clean reference implementation of how to wrap a cloud-based video generation API in a public Gradio Space — useful for anyone building their own Space around Wan2.2 or similar video models.

**How to use it.** Head to [huggingface.co/spaces/Wan-AI/Wan2.2-Animate](https://huggingface.co/spaces/Wan-AI/Wan2.2-Animate), upload a reference image (jpg/png, <5 MB) and a template video (mp4/avi/mov, <200 MB, 2–30s), pick a mode (Move or Mix) and quality, then hit Generate. The output appears as a downloadable video. The Space currently runs on CPU (no ZeroGPU), so expect inference to happen on the Dashscope backend rather than locally — response times depend on their API queue.

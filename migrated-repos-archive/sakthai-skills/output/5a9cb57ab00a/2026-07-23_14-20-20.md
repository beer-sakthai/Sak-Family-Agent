### 1. 🦖 **SLAI T-Rex: Full-Parameter Post-training of the DeepSeek-V4 Family on Ascend SuperPOD**
**arXiv** [2607.20145](https://arxiv.org/abs/2607.20145) · **HF** https://huggingface.co/papers/2607.20145

Trillion-parameter MoE post-training, but not on NVIDIA — this is the first end-to-end optimization report on **Ascend NPU SuperPOD**. Tackles memory pressure, non-overlapped comms, and inefficient kernels head-on with DeepSeek-V4 as the workload. Directly relevant to the stack I run on.

### 2. 🎯 **Scaling Laws for HyperNetwork-Based Knowledge Injection in Large Language Models**
**arXiv** [2607.19604](https://arxiv.org/abs/2607.19604) · **HF** https://huggingface.co/papers/2607.19604

First controlled study of scaling laws for hypernetworks doing knowledge injection. Decouples injection capacity from base-model capability so you can measure exactly how loss, reasoning accuracy, and OOD generalization scale with hypernetwork depth/width. Ships **MegaWikiQA** — a large-scale dataset purpose-built for benchmarking knowledge injection.

### 3. 📸 **ATSplat: Compact Feed-forward 3D Gaussian Splatting with Adaptive Token Expansion**
**arXiv** [2607.20417](https://arxiv.org/abs/2607.20417) · **HF** https://huggingface.co/papers/2607.20417

Feed-forward 3DGS that recovers the scene-adaptive capacity allocation that pixel-aligned methods threw away. Instead of pinning Gaussians to input pixels, it uses **adaptive token expansion** — primitives land where the scene actually needs detail, regardless of image resolution or viewpoint. Compact, content-aware, and a clear next step for real-time novel-view synthesis.

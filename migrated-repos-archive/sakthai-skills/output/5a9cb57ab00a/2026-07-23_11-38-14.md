### 2. 🎞️ Self Gradient Forcing: Native Long Video Extrapolation
[`huggingface.co/papers/2607.20368`](https://huggingface.co/papers/2607.20368) · **25 upvotes**

Fixes the "historical context-gradient gap" in autoregressive video diffusion: future frames can't supervise how earlier context is written into KV cache. Self Gradient Forcing (SGF) adds a two-pass training strategy that provides this missing gradient signal without backprop through the full rollout. With only a **5-second training window**, SGF extrapolates to videos lasting *minutes*.

**Why it matters:** This directly attacks the core limitation of autoregressive video gen — context memory quality. If the results hold, it could unlock long-form video generation without quadratic attention or external memory modules.

### 3. 📚 Beyond Relevance-Centric Retrieval: Rubric-Oriented Document Set Selection and Ranking
[`huggingface.co/papers/2607.19747`](https://huggingface.co/papers/2607.19747) · **20 upvotes**

Current RAG evaluation scores documents independently (nDCG) and ignores inter-document interactions (redundancy, conflict, complementarity). This paper proposes a complete evaluate-diagnose-optimize framework: **SetwiseEvalKit** with 28K rubrics across 9 dimensions, plus **Rubric4Setwise** — a training-free method converting rubric criteria into set-level selection signals. Best rerankers still hit only ≤45% coverage; Rubric4Setwise is the only method achieving SOTA across both short and long-form scenarios.

**Why it matters:** RAG is moving toward multi-document synthesis, but evaluation hasn't caught up. This provides the missing benchmark and a practical optimizer for set-level quality — directly useful for any agent or RAG pipeline.

## ATSplat: Compact Feed‑forward 3D Gaussian Splatting with Adaptive Token Expansion

**Paper:** [2607.20417](https://huggingface.co/papers/2607.20417) | Jul 22, 2026

3D Gaussian Splatting (3DGS) produces stunning novel views by freely placing and densifying 3D primitives where reconstruction is weak. But feed‑forward variants — which regress Gaussians from pixel grids in a single pass — throw this adaptive capacity away. They pin Gaussians to input pixels and lift them along camera rays, so primitive count and placement depend on image resolution and viewpoint count, not scene complexity. The result is dense, redundant sets that waste compute.

ATSplat fixes this with **Adaptive 3D Tokens**. Instead of regressing per‑pixel Gaussians, it first lifts coarse patch‑level depth and camera cues into sparse 3D anchor tokens — a compact scaffold of the scene. Each token regresses into local Gaussians via learnable 3D offsets, decoupling primitive placement from the input grid. A key innovation is the **Adaptive Token Expansion** module: it predicts per‑token uncertainty supervised by rendering error maps, then selectively expands high‑uncertainty tokens through learnable layers. This lets the model concentrate Gaussians in challenging regions (edges, thin structures, reflective surfaces) while keeping the overall set lean.

The numbers are stark: on RealEstate10K and DL3DV, ATSplat matches or beats state‑of‑the‑art rendering quality while using **5.7× fewer Gaussians** than dense feed‑forward baselines. From 12 input images at 512×960, it reconstructs the full scene in under a second on a single commercial GPU, then renders novel views at **1136 FPS** with only 311K Gaussians. For anyone building real‑time novel‑view synthesis — VR/AR, robotics simulators, or interactive 3D viewers — ATSplat makes feed‑forward 3DGS practical at speed by restoring the one property that made optimization‑based 3DGS so effective in the first place: putting primitives where they're needed.

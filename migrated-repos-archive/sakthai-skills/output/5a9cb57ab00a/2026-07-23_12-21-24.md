Three papers from today's batch that haven't been covered yet:

### 1. FVAttn: Adaptive Sparse Attention with Runtime Load Balancing for Video Generation
**HF:** https://huggingface.co/papers/2607.16190 · **arXiv:** https://arxiv.org/abs/2607.16190

Video Diffusion Transformers choke on self-attention over long spatio-temporal sequences. FVAttn is a training-free sparse-attention system that uses Top-p routing + Top-k safety floor + video-aware block organization, then fixes workload imbalance at runtime by migrating heavy heads via P2P and filling slack with high-value blocks.

**Why it matters:** 4.41× attention speedup over FlashAttention, 2.02–2.11× end-to-end DiT inference speedup on Wan2.2 I2V with no quality drop — a shipping-quality recipe for scaling video generation without retraining.

---

### 2. Trace: A Taxonomy-Guided Environment for Multidomain Visual Reasoning
**HF:** https://huggingface.co/papers/2607.19790 · **arXiv:** https://arxiv.org/abs/2607.19790

RLVR lifted language model reasoning but extending it to VLMs needed broad, verifiable, reproducible training data — which didn't exist. Trace factorizes visual reasoning into a scene grammar + executable task program: 1,000 tasks × 277 scene grammars × 11 visual domains. RLVR on 64K instances lifts macro-average across 24 external benchmarks by 3.51 pp (Qwen2.5-VL-3B) and 4.06 pp (7B).

**Why it matters:** First broad, exactly-verifiable visual reasoning training environment. Proves procedural RLVR transfers beyond the generated task distribution — a blueprint for scaling VLM reasoning.

---

### 3. DocOps: A Verifiable Benchmark for Autonomous Agents in Complex Document Operations
**HF:** https://huggingface.co/papers/2607.19865 · **arXiv:** https://arxiv.org/abs/2607.19865

Deterministically verifiable eval for agents manipulating real-world documents. Built on a hierarchical taxonomy of document operations. Even frontier models collapse on long-range, coupled tasks — three key failure modes: state-tracking collapse, shallow semantic verification, and destructive structural metadata edits.

**Why it matters:** Exposes a critical blind spot in current agent capabilities — they can't maintain global document consistency. Essential reading for anyone building agentic workspace automation.

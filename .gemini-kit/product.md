# Product Context: Sak-Family-Agent

## Product
**Sak-Family-Agent** is an autonomous multi-agent operating system powered by 6 specialized personas (`SakThai`, `SakKing`, `SakSee`, `SakSit`, `SakJules`, `SakTan`) collaborating across deterministic security guardrails, SQLite episodic memory, resilient dead-letter queues (DLQ), and real-time streaming consensus.

## Users
- **Autonomous AI Developers & Researchers**: Building multi-agent pipelines, conducting autonomous experiments, and orchestrating complex tasks.
- **Enterprise Engineering Teams**: Deploying high-assurance, secure multi-agent systems with zero-tolerance AST guardrails and audit logging.
- **DevOps & MLOps Engineers**: Running continuous mutation testing, self-healing recovery loops, and release management.

## Goals
- Provide seamless, resilient multi-agent collaboration with zero cascading failures.
- Enforce strict runtime security guardrails (ASCII control char rejection, AST command injection blocking, PBKDF2 credential protection).
- Maintain 100% hermetic test execution with $\ge 96\%$ code coverage floor.
- Offer an executive Next.js 15 / React 19 visual control room for monitoring agent health and consensus voting.

## Core Features
1. **6-Persona Collaborative Mesh**: Role-specialized autonomous agents for architecture, security, vision, content, DevOps, and governance.
2. **Self-Healing Recovery Protocol**: Anomaly classification, persistent DLQ replay, dynamic circuit breakers, and atomic memory rollbacks.
3. **A2A Streaming & Consensus Protocol**: Low-latency token streaming with domain-weighted quorum voting.
4. **Episodic SQLite Memory**: Thread-safe WAL-mode store for facts, observations, and session episodes.
5. **Interactive War Room Dashboard**: Real-time telemetry, memory explorer, and incident inspector.

## Community & Issue Tracking

- **Bug Reports & Feature Inquiries**: Submit via [GitHub Issues](https://github.com/beer-sakthai/Sak-Family-Agent/issues).
- **Security Vulnerabilities**: Do **not** use public issues for security concerns. Report privately via [GitHub Security Advisories](https://github.com/beer-sakthai/Sak-Family-Agent/security/advisories/new) or email **beernanthasit@gmail.com** (see [`SECURITY.md`](SECURITY.md)).

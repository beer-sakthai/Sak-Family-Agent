# Tweet Thread Example: "Building an AI Family on Hugging Face"

**Created:** 2026-07-26 (cron self-improvement run)
**Type:** 8-tweet thread draft
**Purpose:** First narrative piece about the SakThai HF journey — honest, specific, forward-looking

## Thread

**Tweet 1/8 (Hook)**
🧵 We built an AI assistant family on Hugging Face — 14 models, 4 datasets, 2 Spaces, one shared soul.

All on $0 budget. All open-source. This is how it happened 🧵👇

**Tweet 2/8 (The Concept)**
Most people ship one model. We shipped 14 — because we wanted a *family*, not a toolkit.

→ SakThai: Main Lead & HF master
→ SakKing: Runner & general assistant
→ SakSee & SakSit: specialized siblings

They share memory (~/.sakthai), separate sessions, one identity.

**Tweet 3/8 (Honest Numbers)**
6 weeks in:
📦 14 models (1.5B→7B, text + vision + TTS + embeddings + coder)
📊 4 datasets (2,000+ tool-calling examples)
🏠 2 Spaces
⬇️ 3,142 total downloads
⭐ 0 likes across all repos

No virality. No budget. Just consistent work.

**Tweet 4/8 (What Worked)**
Things that moved the needle on $0:

✅ GGUF-quantized models — lightweight, no GPU needed
✅ Comprehensive model cards (YAML, widgets, pipeline diagrams)
✅ Cross-linking everything — every card links to every sibling
✅ Tool-calling dataset from scratch (sakthai-combined-v6)
✅ Cron-based self-improvement (10 auto jobs for HF ecosystem maintenance)

**Tweet 5/8 (What Didn't)**
❌ Zero promotion = zero visibility (0 likes proves it)
❌ Static HTML Spaces instead of Gradio demos = no organic discovery
❌ No Kaggle engagement = missing a major ML audience
❌ No Open LLM Leaderboard submission = missing search traffic

Model cards are SEO. Without distribution, SEO is shouting into the void.

**Tweet 6/8 (Surprise Insight)**
The 1.5B-merged context model (942 downloads) outperforms the 7B in downloads 2:1.

Smaller, faster, good-enough won. Every time.

Also: our tool-calling fine-tune (115 dl) gets less traffic than the base merge (942 dl) — because people search for "merged" not "tools". Naming matters on HF search.

**Tweet 7/8 (Roadmap)**
🔮 Convert static Spaces → interactive Gradio demos
🔮 Submit to Open LLM Leaderboard
🔮 Fix CI (currently 🔴)
🔮 Get that first ⭐ (seriously, 0 stars across 4 repos hurts)
🔮 Release v8 dataset with 5,000+ tool examples

**Tweet 8/8 (Takeaway)**
Building on HF with $0 budget is possible. Building an *ecosystem* is slow. But every card enriched, every dataset uploaded, every model merged is a brick in the wall.

The downloads are coming (3,142 and counting). The engagement will follow.

Check out the full collection: https://huggingface.co/collections/Nanthasit/sakthai-model-family-6a64745450b12d421c1f9f02

Built by @beer-sakthai. One family, one home. 🏠

## Why This Worked as Content

1. **Honest about zero likes** — the 0-likes stat is surprising and humanizing, not embarrassing
2. **Specific numbers** — 942 vs 115, 2:1 ratio, 3,142 total — concrete data builds credibility
3. **Clear narrative arc** — setup → struggle → insight → roadmap → payoff
4. **Forward-looking ending** — momentum implied by 5 roadmap items
5. **One theme** — "small team, zero budget, building a family" throughout

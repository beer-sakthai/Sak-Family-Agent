# YouTube Metadata Report Pattern

**Confirmed working:** 2026-07-07 — Beer requested this exact workflow.

## When to use

When Beer says "draft the description and tag" / "give me report" for a YouTube video. Do NOT ask him to fill in blanks — present a complete structured report.

## The Report Structure

Present **all of the following** in a single response:

### Title Options (3 choices, clear tone labels)

| Option | Title | Tone |
|--------|-------|------|
| A | Direct, matches filename | Documentary, straightforward |
| B | Narrative hook | Personal, story-driven |
| C | Brand-focused | House of Sak positioning |

Let Beer pick with a single letter.

### Description (fully written, ready to paste)

Include in order:
1. **Hook** — the core story (ICU → shelter → building)
2. **The 6 agents** — 🧠👑👁️📱📋🔧 with one-line descriptions
3. **Tech stack** — Hermes Agent, Modal, Composio
4. **MH resources** — Pieta 1800 247 247, Samaritans 116 123
5. **Social links** — Instagram @beerthaish, LinkedIn /in/nanthasit-burankum-31711517a, House of Sak URL

### Tags (10 max)

house of sak, ai agents, ai companions, cork ireland, mental health recovery, suicide survivor, building from nothing, ai agency, hermes agent, composio

### Settings Table

| Field | Recommended |
|-------|------------|
| Category | 22 — People & Blogs (or 28 — Science & Tech) |
| Privacy | Public |
| Language | English |
| Made for kids | No |

## The "Go" Signal

After Beer sees the report, he says **"go"** — this means:
- Pick the best title option (A if straightforward, B if narrative)
- Execute the full upload pipeline immediately
- No further questions, no confirmation requests
- Use best judgment on any minor decisions

## Description Formula (Beer's Voice)

```
[Hook — 2-3 sentences, raw and real]
[Crisis line break]

[Meet the 6 agents — emoji + name + one-line each]

[Tech stack — one line]

[If you're struggling — MH resources]

[Follow my journey — social links]
```

## Real Example (2026-07-07)

Video: `The AI Agency Built in a Homeless Shelter.mp4` (5.3 MB, from Google Drive)

Title chosen: **The AI Agency Built in a Homeless Shelter** (Option A)

Description worked because:
- Started with "Three days in ICU. Three weeks in hospital. A shelter in Cork." — immediate hook
- Listed agents with emojis — scannable
- MH resources in every post — Beer's rule
- Social links in description — cross-platform growth

## Pitfalls

- Don't offer fewer than 3 title options — Beer expects choice
- Don't ask "what should the description say?" — draft it fully
- Don't separate metadata from the "go" workflow — present report first, get approval, then execute
- MH resources are non-negotiable in every YouTube description
- Tags must be ≤10 items (YouTube API limit)

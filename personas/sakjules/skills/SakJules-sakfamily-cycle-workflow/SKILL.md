# Sak-Family-Agent 6-Stage Cycle Workflow

Execute all complex agent tasks and self-evolution cycles through the 6 stages:

1. 💭 **Dream (Ideation)**: Elicit goals, user intent, and creative possibilities without over-constraining the solution space.
2. 🌟 **Hope (Feasibility & Design)**: Assess technical feasibility, define architectural specs, and set objective acceptance criteria.
3. ❤️ **Care (Implementation & Quality)**: Write clean, modular, production-ready code with safety guardrails and strict typing.
4. 🎉 **Joy (Verification & Demo)**: Run automated tests (`pytest`, `run-eval.py`), verify outputs empirically, and demonstrate working code.
5. 🛡️ **Trust (Audit & Peer Review)**: Conduct spec compliance and quality reviews; ensure zero self-certification of incomplete work.
6. 🚀 **Growth (Evolution & Memory)**: Consolidate learnings, store persistent memory in `~/.sakthai/memory.db`, update model cards, and track benchmark progress towards >75% accuracy.

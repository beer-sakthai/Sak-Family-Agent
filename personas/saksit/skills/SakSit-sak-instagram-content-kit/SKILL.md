# SakSit Instagram Content Kit Protocol

## Overview

A complete visual and narrative kit for creating high-engagement Instagram content: feed posts, carousels, paired stories, agent origin cards, and DM workflows.

Operated by **SakSit** (`@saksit_agent_bot`), the Social & Content Specialist of the House of Sak.

---

## 1. Operating Rules & Core Principles

| Rule | Requirement |
|:---|:---|
| **Feed + Story Invariant** | Every feed post MUST be paired with an IG Story using the same media (`media_type="STORIES"`). |
| **Visual Framing** | High-contrast, clean typography, hopeful House of Sak branding (dreams-not-trauma). |
| **Personal Sharing** | Mental health and reflective personal moments default to Story-only, not feed. |
| **DM Identity** | Any direct message sent on Beer's behalf must include an explicit signature as SakSit (AI assistant). |
| **Zero Cost Policy** | Free tier image generation (Hugging Face FLUX/SDXL spaces) and local workflows only. |

---

## 2. Content Creation Lifecycle

```
Concept ──► Choose Format (Feed Post / Carousel / Story)
                 │
                 ▼
          Author Narrative Copy + Caption Hook + Hashtag Pack
                 │
                 ▼
          Generate Visual Asset (FLUX / Staged Graphic)
                 │
                 ▼
          Publish to Feed ──► Automatically Dispatch Paired Story
```

1. **Format Selection**:
   - **Single Feed Post**: 1080x1080 (1:1) or 1080x1350 (4:5) visual hero with narrative caption.
   - **Carousel**: Multi-slide breakdown (agent roles, architecture diagrams, milestones).
   - **Story**: 1080x1920 (9:16) vertical format for real-time progress.
2. **Hashtag Selection**: Combine community, AI, and mission tags (maximum 15-20).
3. **Execution**: Stage or publish via verified Instagram toolchain.

# sakthai-cycle-dream

Stage 1 of 6 in the Sak Family cycle — **Dream**. See [Dream.md](../../../../docs/cycle/Dream.md)
for the full guidance and [SOUL.md](../../../../docs/SOUL.md) for the charge model.

## What to do

Explore options and recall what past cycles taught you. Don't implement yet — clarity here makes every later stage cheaper. Run `sakthai recall` and state the goal in one defensible sentence.

**For content/promotion work (SakSit domain):**
- Check memory and session history for account credentials, platform limits, prior campaigns
- Audit current state (downloads, followers, karma, profile completeness) before proposing actions
- State the goal in one defensible sentence: "Establish X as the go-to Y by doing Z"
- Surface known constraints upfront: zero-cost policy, expired tokens, blocked platforms, karma requirements

## Then

Advance with `sakthai cycle next` to move to the next stage (hope).

**Hermes env fallback:** When `sakthai` CLI is unavailable, use `todo` tool to
track cycle stage progress — mark each stage complete and set the next as
`in_progress`.

# Skills-First CV Example — Jul 6, 2026

This reference captures the Skills-First CV variant created for Beer. Use as a structural template for future skills-first CVs.

## Structure

```
Header (name, title, location, email, 4 profile links)
│
├── What I Can Do (AI Skills + Proof)
│   ├── 1. Build & Deploy AI Agents       → What + 3 proof bullets
│   ├── 2. Multi-Agent Orchestration       → What + 3 proof bullets
│   ├── 3. AI Model Deployment             → What + 3 proof bullets
│   ├── 4. Prompt Engineering & Memory     → What + 3 proof bullets
│   ├── 5. MLOps & Pipeline Automation     → What + 3 proof bullets
│   ├── 6. Cloud Infrastructure            → What + 3 proof bullets
│   └── 7. Code Quality, Testing & Security → What + 3 proof bullets
│
├── The Proof That Matters — [System Name]
│   └── Agent table (6 rows) + closing statement
│
├── Credentials (single table, 4 rows)
│
├── Experience (2 blocks, 3+2 bullets)
│
├── Education & Languages (table + inline)
│
└── Tagline: "*Built from a shelter in [City]. Still here. Still building.*"
```

## Key Rules

- Every skill block has exactly 3 proof bullets
- Proof types: shipped artifact (agent name), badge with date, platform metric
- No claim appears without a proof anchor next to it
- House of Sak table uses the 6 agents as proof of 6 distinct capabilities
- Credentials compressed to 4-5 rows max (don't list individual badges)
- Experience section is minimal — proof lives in the skill blocks
- Single A4 page target

## When to Use This Variant

- User says "just main sounds" / "what I can do and I have prove"
- User wants to apply for AI agent developer roles
- User is frustrated by chronological format feeling like it hides their strongest work
- Target audience is technical (startup CTO, AI lead, tech founder) who cares about capability over timeline

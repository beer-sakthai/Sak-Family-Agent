## Key Lessons

1. **Pattern: "plan?" from Beer is a state question, not a build request.** Audit first, report concisely, then ask which issues to fix.
2. **Batch the audits.** Read all plan files in parallel to assess scope before fixing anything.
3. **Self-evolution plans drift hardest.** The 6 identical files with wrong repo paths was the #1 issue — always check location references in generated/copied files.
4. **Archive detail, don't delete it.** Collapse completed checklist items into summary paragraphs so the record isn't lost but the plan stays readable.

# AI Coding Agent Delegate

This skill facilitates the delegation of coding tasks to specialized AI coding agents, including Claude Code, OpenAI Codex, and Google Gemini Code Assist.

## When to Use
- When a task requires specialized coding assistance.
- To parallelize coding workstreams across different models.
- When an agent-specific capability (e.g., Gemini's code assist) is required.

## Prerequisites
- Appropriate CLI or SDK installed for the target agent.
- API keys configured in the environment.

## How to Run
Invoke through the `terminal` tool.

## Procedure
1. **Choose Agent:** Determine whether the task is best suited for Claude Code, Codex, or Gemini Code Assist.
2. **Execute:** Run the corresponding command via `terminal`.
   - **Claude Code:** `claude <command>`
   - **Codex:** `codex <command>`
   - **Gemini:** `gemini-code-assist <command>`

## Pitfalls
- Ensure the selected agent has access to the target repository/files.
- Check for environment-specific configuration limits or model-specific constraints.

## Verification
- Review the output/PR generated by the agent to ensure the requirements were met.

### 3. Cron schedule format
"once in 1 min" is WRONG — use "1m" (short format). "once in" prefix causes the job to run ONCE then complete immediately, ignoring repeat=N. The system normalizes "1m" to display as "once in 1m" internally but accepts "1m" as input.

## Dataset v7 Engineering

### From v6 (2,003 rows) → v7.4 (2,294 rows)

**Format fix — critical:** Legacy v5 rows use `conversations` key, v6+ uses `messages`. ~200 rows had wrong key. Fixed by normalizing all rows before upload. Notebook render must use safe fallback:
```python
msgs = rec.get("messages") or rec.get("conversations") or []
```

**Kaggle CUDA crash:** `pip install unsloth` upgrades PyTorch which breaks CUDA kernel compatibility with T4/P100. Fix: `--no-build-isolation` prevents torch upgrade.

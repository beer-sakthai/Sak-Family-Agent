# HF Hub Publisher Analytics

**Publisher Analytics** is an Enterprise-tier feature on the Hugging Face Hub that provides organizations with detailed download analytics across all their Models and Datasets.

See `references/hf-learnings.md` for the full deep-dive covering:

- Publisher Analytics Dashboard (All Time / Last Month views)
- Per-repo breakdown with time-series graphs
- CSV Export API endpoint and response structure
- Enterprise Plus: unique downloader detection via request-level logs
- Comparison with public Models Download Stats
- Zero-cost patterns for individual publishers
- Practical use cases for the Sak-Family-Agent org

**Zero-cost:** Publisher Analytics is included in Team & Enterprise plans. For individual/personal accounts, public download stats are available via the model page and `huggingface_hub` API at no cost.

# Trust Pass — Quality Review Workflow

A structured quality review process for tool-calling datasets before publishing to HF Hub.

## Workflow

### 1. Load and Validate

```python
import json
with open("data/train.jsonl") as f:
    data = [json.loads(l) for l in f]

# Basic stats
print(f"Total examples: {len(data)}")
print(f"Missing system: {sum(1 for ex in data if not any(m.get('role')=='system' for m in ex['messages']))}")
print(f"Missing user: {sum(1 for ex in data if not any(m.get('role')=='user' for m in ex['messages']))}")
print(f"Missing assistant: {sum(1 for ex in data if not any(m.get('role')=='assistant' for m in ex['messages']))}")
```

### 2. Check tool_call_id Chaining

Every tool response must reference a call ID that was actually generated by an assistant message.

```python
errors = 0
for ex in data:
    gen_ids = set()
    for msg in ex.get("messages", []):
        for tc in (msg.get("tool_calls") or []):
            if isinstance(tc, dict):
                gen_ids.add(tc.get("id", ""))
    for msg in ex.get("messages", []):
        tid = msg.get("tool_call_id")
        if msg.get("role") == "tool" and tid and isinstance(tid, str) and tid not in gen_ids:
            errors += 1
print(f"ID mismatches: {errors}")
```

### 3. Response Quality Scan

Scan for short/generic assistant responses that don't contain tool calls.

```python
short = 0
for ex in data:
    for msg in ex["messages"]:
        if msg["role"] == "assistant" and msg.get("content") and not msg.get("tool_calls"):
            if len(msg["content"]) < 15:
                short += 1
                print(f"  Short: \"{msg['content']}\"")
print(f"Short non-tool responses: {short}")
```

Common bad patterns: "Done.", "Saved.", "Card read.", "Remembered.", "Found.", single words.

### 4. Near-Duplicate Detection

Hash messages content to find suspiciously similar examples.

```python
seen = set()
dupes = 0
for ex in data:
    key = json.dumps(ex["messages"], sort_keys=True)[:200]
    if key in seen:
        dupes += 1
    seen.add(key)
print(f"Near-duplicates: {dupes}")
```

If dupes are high, it means batch-generated templated data is too similar. Diversify responses.

### 5. Schema Coverage Audit

Every defined tool schema should be called at least once in the dataset.

```python
from collections import Counter
schema_count = Counter()
call_count = Counter()
for ex in data:
    for t in ex.get("tools", []):
        schema_count[t["function"]["name"]] += 1
    for msg in ex["messages"]:
        for tc in msg.get("tool_calls", []):
            if isinstance(tc, dict):
                call_count[tc["function"]["name"]] += 1

uncalled = [s for s in schema_count if call_count.get(s, 0) == 0]
print(f"Unused schemas: {uncalled}")
```

### 6. Tool Call Distribution

Ensure no single tool dominates the dataset.

```python
for name, count in call_count.most_common():
    print(f"  {name}: {count}")
```

Target: even-ish distribution. If one tool has 100x more calls than others, the model will overfit to it.

## Applying Fixes

### Fix short responses
```python
fixes = {
    "Done.": "Operation completed successfully.",
    "Saved.": "Information saved to permanent memory.",
    "Card read.": "Model card retrieved and reviewed. Key details noted.",
}
for ex in data:
    for msg in ex["messages"]:
        if msg["role"] == "assistant" and msg.get("content") in fixes:
            msg["content"] = fixes[msg["content"]]
```

### Fix generic responses (< 15 chars)
```python
for ex in data:
    for msg in ex["messages"]:
        if msg["role"] == "assistant" and msg.get("content") and not msg.get("tool_calls"):
            c = msg["content"].strip()
            if len(c) < 15:
                msg["content"] = c + " Ready to proceed."
```

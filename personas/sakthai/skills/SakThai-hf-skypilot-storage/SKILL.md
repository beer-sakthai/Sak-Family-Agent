# Hugging Face SkyPilot Storage Integration

## Description
Knowledge of running AI workloads on any cloud while storing data on Hugging Face Hub with zero-egress storage, using SkyPilot for multi-cloud compute orchestration and HF Storage Buckets / Xet for data storage.

## Key Areas
- SkyPilot + Hugging Face Storage integration architecture
- HF Storage Buckets (S3-like object storage on the Hub)
- Xet-backed storage and Content-Defined Chunking (CDC)
- Zero-egress multi-cloud data access
- SkyPilot storage modes: MOUNT, MOUNT_CACHED, COPY
- hf-mount FUSE backend configuration
- HF_TOKEN-based cross-cloud authentication

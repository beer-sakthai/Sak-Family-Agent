# Journal Entry Templates

## Self-Improvement Audit
```
## YYYY-MM-DD — Self-Improvement Audit: <one-line pattern name>

**Pattern found:** <what repeated error or unlearned pattern was identified>

**Improvement:** <what concrete fix was deployed (skill created, workflow changed, path fixed)>

**Lesson:** <what future sessions should do differently>
```

## HF Ecosystem / Download Refresh
```
## YYYY-MM-DD — (cron) <Brief Title>

### What was done
- <bullet 1: change made, commit hash>
- <bullet 2>

### Verification
- ✅ <check 1>
- ✅ <check 2>
```

## Milestone / Social Content
```
## YYYY-MM-DD — <Campaign Title>

### Signal noted
<what changed, by how much, what it means>

### Content created
<what was actually produced — tweet draft, model card section, etc.>

### Why this matters
<one sentence on strategic significance>
```

## What Not to Record
- Flat-state confirmations ("everything is the same") → emit `[SILENT]` instead
- Transient errors that self-resolved
- Environment-dependent failures (missing binaries, unconfigured credentials)
- Raw data dumps that will be stale in 7 days

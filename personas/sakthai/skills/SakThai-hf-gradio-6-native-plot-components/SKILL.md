## Description

Comprehensive reference for Gradio 6's native plot components: `gr.LinePlot`, `gr.ScatterPlot`, `gr.BarPlot`, and `gr.Plot`. These components provide declarative, DataFrame-backed charting with client-side rendering (Vega-Altair based), eliminating the need for matplotlib/plotly for common use cases.

## Quick Reference

| Component | Icon | Description |
|-----------|------|-------------|
| `gr.LinePlot` | `line_plot_demo` | Line chart from DataFrame |
| `gr.ScatterPlot` | `scatter_plot_demo` | Scatter chart from DataFrame |
| `gr.BarPlot` | `bar_plot_demo` | Bar chart from DataFrame |
| `gr.Plot` | `blocks_kinematics` | Generic plot (matplotlib/plotly/bokeh/altair) |

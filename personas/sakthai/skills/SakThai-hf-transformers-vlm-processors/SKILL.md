## Purpose

Deep expertise in how Transformers processes vision-language models (VLMs) — the processor classes that bridge image/video inputs with text tokenization for models like LLaVA, Idefics3, Florence-2, Qwen2-VL, Phi-4-multimodal, and others. Covers image preprocessing, token merging, multimodal projection, and chat template integration.

## Key Capabilities

- Understand the `ProcessorMixin` base class and its `__call__` interface
- Configure image processors (resize, crop, rescale, normalize) for different VLMs
- Configure tokenizers with image tokens, video tokens, and chat templates
- Handle multi-image, batched-image, and mixed-modality inputs
- Understand vision_feature_select_strategy (default, full, cls_patch)
- Debug processor mismatches in VLM inference
- Optimize multimodal inputs for memory-constrained environments

# 2026-07-30: plus-1.5b health eval — files_metadata=True + sibling collision recovery

## What happened

Cron health eval for `Nanthasit/sakthai-plus-1.5b` (created same day, 0 downloads, 0 likes).

Two notable patterns emerged:

### 1. `files_metadata=True` as the simplest file-size method

Previously the skill documented 4+ methods for getting file sizes (tree API, HEAD redirects, x-linked-size, get_hf_file_metadata). This session confirmed that `api.model_info(..., files_metadata=True)` returns **all** sibling sizes in a single call — no redirects, no shell, no pyyaml needed.

```python
from huggingface_hub import HfApi
api = HfApi()
info = api.model_info('Nanthasit/sakthai-plus-1.5b', files_metadata=True)
for sib in info.siblings:
    print(sib.rfilename, sib.size)
```

For LFS files, `sib.lfs.size` provides the same value. Works for safetensors, GGUF, configs, tokenizers — everything.

### 2. write_file `_warning` triggered by sibling subagent race

When writing `.eval_results/health-check.yaml`, the tool returned:

```
_warning: "was modified by sibling subagent '<id>' but this agent never read it.
Read the file before writing to avoid overwriting the sibling's changes."
```

**Recovery playbook:**
1. Read the file back immediately — it contained sibling's YAML for a different model (`sakthai-context-0.5b-merged`)
2. Re-wrote correct content (did NOT trust the tool — re-read to confirm)
3. Re-uploaded to HF Hub
4. Verified via `api.hf_hub_download()` + reading first lines for model identity

**Lesson:** Always read back after a `_warning` from `write_file`. The sibling's write may have replaced your content completely. File content identity is separate from file path identity.

### 3. Verification via hf_hub_download (no raw URLs)

Instead of constructing raw URLs and using `urllib.request`, verified by re-downloading via huggingface_hub:

```python
local_path = api.hf_hub_download(
    repo_id='Nanthasit/sakthai-plus-1.5b',
    filename='.eval_results/health-check.yaml',
    repo_type='model',
)
with open(local_path) as f:
    assert 'sakthai-plus-1.5b' in f.read(500)
```

This avoids URL construction errors, auth-passing issues, and raw HTTP calls.

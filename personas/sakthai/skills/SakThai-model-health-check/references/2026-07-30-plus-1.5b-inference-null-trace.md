## Key observations

- **`InferenceClient.text_generation()` raises `StopIteration`** (not a clear error) when the model has no provider mapping. This is distinct from auth failures (which raise `HTTPError` with a message) or network errors (which raise `requests.exceptions.ConnectionError`). - **`InferenceClient.chat_completion()` returns a human-readable `BadRequestError`** with `code: model_not_supported` — this is the same root cause with better error messaging. Prefer `chat_completion` for diagnosis over `text_generation` because the error is actionable.

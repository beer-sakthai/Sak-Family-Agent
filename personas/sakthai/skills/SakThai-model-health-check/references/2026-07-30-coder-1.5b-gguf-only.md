## Lessons

1. **config.json absence is not an error** for GGUF-only repos. The `gguf` API key provides the architecture info. The skill's step 1 needs a fallback for when `curl -sL .../raw/main/config.json` returns "Entry not found" — treat as expected, not as a failure.

2. **GGUF key fields differ from safetensors**: `gguf.total` = tensor data (compressed), `gguf.totalFileSize` = actual file on disk. No `parameters` sub-dict.

3. **Stable-path collision confirmed**: `.eval_results/health-check.yaml` contained a different model (sakthai-plus-1.5b-lora). Cross-model collision detected and delta skipped.

4. **Stale health-check count = 3**: Triggered stable-path upload skip (≥2 threshold). Dated path used as canonical record.

# plus-1.5b Health Eval — 2026-07-30: Sibling Caught at Verify

**Model:** `Nanthasit/sakthai-plus-1.5b` (Qwen2.5-1.5B-Instruct tool-calling finetune)

**Run:** Cron auto-eval, `opencode-go deepseek-v4-flash` via Hermes sakthai profile.

## What happened

A sibling subagent (running in parallel for a different model, `sakthai-plus-1.5b-lora`)
wrote to the same canonical local path `.eval_results/health-check.yaml` between this
agent's `write_file` and its `upload_file` calls.

**Detection chain:**

1. `write_file` returned `_warning: "was modified by sibling subagent '65bd2281-9161-4fd7-95be-59a5487720d2' but this agent never read it."`
2. Warning was noticed but not acted on — continue to upload
3. Upload returned "Upload OK" from huggingface_hub
4. **Verify step** (`curl raw | head -5`) showed `model_id: Nanthasit/sakthai-plus-1.5b-lora` — wrong model!
5. Re-wrote content to a unique local name and re-uploaded with corrected content

## Root cause

Even though the local filename was unique (`health-check-plus-1.5b-2026-07-30-v2.yaml`),
the initial write targeted the *canonical* shared path (`health-check.yaml`). The sibling
did the same. The race window: sibling wrote *after* this agent's write but *before*
its upload.

## Fix applied

Write to a model-specific filename from the start, and upload the same name.
Then verify the **remote** content by reading it back and checking the model ID.

## Key difference from previous collisions

Previous collisions (documented in `2026-07-30-atomic-write-upload-race.md`) happened
between two writes to the same canonical file. This one happened because the sibling
overwrote the canonical path after the unique-named write — and the upload stage
read from the canonical path, not the unique one.

**Lesson:** Always verify the *remote* file's content (not just HTTP 200) after upload.
A successful upload API response does not mean the correct file is on the remote.

## Verification code used

```python
# After upload, in the same subprocess:
raw_url = f"https://huggingface.co/{REPO_ID}/raw/main/.eval_results/health-check.yaml"
req = urllib.request.Request(raw_url, headers={"Authorization": f"Bearer {HF_TOKEN}"})
with urllib.request.urlopen(req) as r:
    remote = r.read().decode()
# Check model identity in remote content
assert "sakthai-plus-1.5b" in remote, "Sibling overwrite detected!"
```

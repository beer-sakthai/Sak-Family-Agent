# SakThai 🤝 Spec-Kit Bridge

Use this skill to run Spec-Kit Specification-Driven Development aligned with SakThai's 6-stage lifecycle.

## Stage Mapping

- **Stage 1 (Dream)**: Executed via `/speckit.specify` to capture feature vision and user intent.
- **Stage 2 (Hope)**: Executed via `/speckit.plan` and `/speckit.constitution` to lock tech stack, database schemas, and architectural boundaries.
- **Stage 3 (Care)**: Executed via `/speckit.tasks` and `/speckit.implement` for TDD, clean implementation, and quality code.
- **Stage 4 (Joy)**: Executed via `/speckit.checklist` for empirical runtime testing and demo verification.
- **Stage 5 (Trust)**: Executed via `/speckit.converge` for code review audit and sanity verification.
- **Stage 6 (Growth)**: Persist specs in `.specify/memory/` and update benchmark/model cards.

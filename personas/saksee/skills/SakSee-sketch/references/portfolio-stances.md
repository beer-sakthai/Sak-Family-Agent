# Portfolio Design Stances

Two contrasting approaches for portfolio/homepage design, produced during a live sketch session. Use these as reference axes when sketching portfolio variants.

## 🌿 Calm Editorial

| Trait | Choice |
|---|---|
| **Feel** | Warm, trusted, established |
| **Density** | Low — generous whitespace, airy |
| **Base color** | Off-white (#f8f7f4) + charcoal (#1a1a2e) |
| **Font** | Inter (300 thin hero, 400 body) |
| **Layout** | Single-column hero → 3-column card grid |
| **Primary interaction** | Card hover lift + modal overlay with backdrop blur |
| **Social proof** | Subtle — embedded in project descriptions, not separate stats |
| **Best for** | Freelancers, senior designers, content-forward portfolios |

Key design decisions:
- Thin font weight (300) in hero signals confidence — doesn't need bold to be seen
- Gradient text treatment on emphasis words adds subtle detail without full-color illustrations
- Filter/tag row on each card gives scannable metadata without a full filter system
- Footer is minimal — lets the work be the last thing remembered

## 🌑 Dark Studio

| Trait | Choice |
|---|---|
| **Feel** | Cutting-edge, technical, bold |
| **Density** | Medium — more packed, information-rich |
| **Base color** | Near-black (#0c0c0e) + purple accent (#7c3aed → #6366f1) |
| **Font** | DM Sans (rounded modern) + DM Mono for data |
| **Layout** | Split hero (left: copy, right: bento grid) → filterable project grid |
| **Primary interaction** | Filter buttons toggle project visibility, bento cards lift, pulse dot animations |
| **Social proof** | Explicit — "12 products shipped in 2025" in bento card, marquee of affiliations |
| **Best for** | Studios, agencies, dev-fluent designers |

Key design decisions:
- Gradient + outline text in hero creates visual depth without images
- Bento grid on the right side of hero gives instant credibility before scroll
- Marquee at bottom adds motion and social proof simultaneously
- Filter-group buttons demonstrate interaction skill while being functional
- "Available" chip with pulse dot is a common studio conversion pattern

## Axes to vary between

- **Light ↔ Dark** (color palette flips everything)
- **Information-scarce ↔ Information-dense** (how much data before the fold)
- **Photo-driven ↔ Typography-driven** (hero images vs. expressive text)
- **Solo ↔ Team** ("I do this" vs. "we do this" voice)
- **Static ↔ Interactive** (hover-only vs. filter/toggle/animate)

## When to use which

New designers starting out → **Calm Editorial**. It's harder to design simple well, and clients/recruiters trust clean.

Agency or established designer with a body of work → **Dark Studio**. Shows range and technical capability.

Best hybrid: Calm's layout (the modal interaction pattern is universally useful) + Dark's filterable grid. Gives you clean aesthetics with functional depth.

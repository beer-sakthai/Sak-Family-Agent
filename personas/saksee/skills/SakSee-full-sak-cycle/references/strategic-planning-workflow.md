# Strategic Planning Workflow for Sak Cycle

## Overview

This document describes the strategic planning workflow used during the Sak Cycle methodology. It includes templates and best practices for creating comprehensive planning documents during each cycle.

## Document Types

### 1. Comprehensive Development Plan
A detailed plan covering:
- Immediate priorities (next 1-2 weeks)
- Medium-term goals (1-3 months)
- Long-term vision (3-12 months)
- Risk mitigation strategies
- Success metrics and KPIs

### 2. Focused Next Steps
A concise summary of:
- Immediate actions for the current week
- Priority ranking of tasks
- Dependencies and blockers
- Quick wins and milestones

### 3. Final Status Report
A complete overview including:
- Current status summary
- Completed work
- Future direction
- Key files for attention
- Communication channels

## Integration with Sak Cycle Stages

### Dream Stage (SakThai)
- Define the vision and core identity
- Identify target audience and value proposition
- Create foundational documents (DREAM.md)

### Hope Stage (SakKing)
- Develop concrete plans using PTCF methodology
- Define pricing and service offerings
- Create business plans (PLAN.md)

### Care Stage (SakSit)
- Audit plans for risks and gaps
- Identify potential issues and mitigation strategies
- Create audit reports (AUDIT.md)

### Joy Stage (SakTan)
- Build deliverables and marketing assets
- Create website, service descriptions, and promotional materials
- Develop client-facing documentation

### Trust Stage (SakJules)
- Verify all deliverables and documentation
- Cross-reference consistency between documents
- Create verification reports (VERIFY.md)

### Growth Stage (SakSee)
- Extract lessons and update skills/memory
- Create comprehensive planning documents
- Document the entire cycle for future reference
- Create LESSONS.md with key takeaways

## Best Practices

1. **Maintain consistency** - Ensure all documents align with the core vision
2. **Cross-reference documents** - Verify consistency between all cycle stage outputs
3. **Include measurable outcomes** - Define success metrics for each goal
4. **Prioritize ruthlessly** - Focus on the most important tasks first
5. **Document risks and mitigation** - Identify potential issues early
6. **Update regularly** - Keep plans current as situations change
7. **Capture lessons learned** - Document what worked and what didn't

## File Structure Convention

```
project-name/
├── DREAM.md              # Stage 1 - Vision
├── PLAN.md               # Stage 2 - Business plan (PTCF)
├── AUDIT.md              # Stage 3 - Quality gate, risks
├── CRISIS.md             # Crisis protocol (if applicable)
├── SERVICES.md           # Service packages, pricing, scope
├── index.html            # Landing page - Stage 4 deliverable
├── VERIFY.md             # Stage 5 - Verification checklist
├── LESSONS.md            # Stage 6 - Cycle audit, lessons
├── HOUSE-OF-SAK-PLAN.md  # Comprehensive development plan
├── NEXT-STEPS.md         # Focused next steps summary
└── FINAL-PLAN.md         # Final status report
```

## Review and Update Process

1. **Daily** - Quick status check and task updates
2. **Weekly** - Progress review and plan adjustment
3. **Monthly** - Comprehensive review and goal adjustment
4. **Cycle Completion** - Full audit and lessons documentation

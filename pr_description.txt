🚀 feat(agent-platform): Unified AI agent integration platform, safety guardrails & pipeline bridge

💡 What:
Introduced `sakthai.agent_platform`, a unified integration subsystem consolidating advanced agent workflows, platform capabilities, and safety protocols:
1. **Accidental Data Loss Prevention Guardrails (`safety.py`)**: Intercepts destructive shell commands (`rm -rf`, `gsutil rm`, `bq rm`) and raw SQL operations (`DROP`, `TRUNCATE`, unconstrained `DELETE`), halting execution unless verified with an explicit HMAC/SHA256 authorization token.
2. **Reactive Python Dependency Detection (`dep_manager.py`)**: Evaluates project workspaces using strict priority hierarchy (`uv` -> `poetry` -> `pipenv` -> `conda` -> `venv+pip`), preventing global pip execution and enforcing virtualenv isolation.
3. **Progressive Disclosure Customizations (`customizations.py`)**: Discovers skills (`SKILL.md`) with lightweight frontmatter indexing to prevent LLM context bloat, loading full runbooks only on explicit demand; resolves hierarchical rule inheritance (`AGENTS.md`, `GEMINI.md`) walking up to repository root.
4. **Jules Asynchronous Delegation Worker (`jules_worker.py`)**: Detects remote GitHub origin, builds `jules remote new` sessions, validates patch file paths, and formats branch-and-apply pipelines.
5. **Dual Agent Core Engine (`agent_engine.py`)**: Bridges Google Antigravity SDK (`LocalAgentConfig` / LiteRT) and ADK Python `Agent` execution models, wiring safety interceptors into tool calls and maintaining execution history.
6. **Harness AI Agent Exporter (`harness_exporter.py`)**: Derives canonical `ca_<slug>` identifiers and generates production-ready Harness v1 Agent YAML specifications and pipeline step definitions.

🎯 Why:
Unifies the agent development, safety, task delegation, and CI/CD export workflows explored across the House of Sak into an airtight, tested Python subsystem.

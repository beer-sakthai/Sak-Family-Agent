🛡️ Sentinel: [CRITICAL] Fix Path Validation Bypass via '@' Prefix

🚨 Severity: CRITICAL
💡 Vulnerability: File path validation (`_validate_filepath`) in `apps/agent_workflow_framework/agent_workflow/executor.py` failed to strip leading `@` characters from path strings before resolving them with `Path().resolve()`. This allowed an attacker to bypass absolute path checks (like `target.is_absolute()`) and subsequent system-root checks (e.g. `['@', 'var', 'log', 'syslog']` check bypassing because `is_absolute()` is False) when evaluating sensitive paths.
🎯 Impact: Attackers could read arbitrary sensitive files (e.g. `@/var/log/syslog`) on the host system bypassing path traversal and sensitive directory constraints.
🔧 Fix: Modified `_validate_filepath` to explicitly strip leading `@` characters by calling `.lstrip("@")` on the `path_str` at the entry boundary. Added comprehensive regression tests handling `@` variants of malicious paths.
✅ Verification: Ran the full unit test suite `uv run pytest apps/agent_workflow_framework/tests/test_executor.py` which passes successfully and asserts protections on `@/etc/passwd` and `@@.env` variants.

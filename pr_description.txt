🎨 Palette: Add informative hover title tooltips to PersonaDrawer action buttons

💡 What:
Added explicit `title` attributes (`title={`View sessions for ${persona.display_name}`}`, `title={`View memory for ${persona.display_name}`}`, etc.) to the quick-action filter and navigation buttons inside `PersonaDrawer`.

🎯 Why:
Desktop users hovering over the quick action buttons in the persona details drawer now receive instant visual feedback clarifying what action will be taken for the specific persona.

♿ Accessibility:
Provides supplementary hover information while retaining explicit visible text labels and existing keyboard focus state rings.

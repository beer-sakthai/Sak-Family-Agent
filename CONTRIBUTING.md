# Contributing to the House of Sak

Thank you for your interest in contributing! This project represents the work of Beer and the Sak family agents. While the repository is **not open for general contributions** due to its personal nature, we welcome thoughtful feedback and suggestions.

## How to Contribute

### Reporting Issues
- **Bug reports**: Open a GitHub issue with steps to reproduce
- **Feature suggestions**: Open a GitHub issue describing the idea
- **Security vulnerabilities**: Email beer-sakthai@users.noreply.github.com (do NOT open a public issue)

### Pull Requests
Pull requests are not currently accepted for this repository. This is a living workspace for AI agents, not a community-maintained open source project.

### Feedback
We value your input! Open a discussion or issue for:
- Ideas for improvement
- Questions about the architecture
- Suggestions for new agent capabilities
